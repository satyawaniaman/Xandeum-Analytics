# Welcome to Xandeum Analytics

**Xandeum Analytics** is a community-built monitoring platform for the Xandeum decentralized storage network. It provides real-time visibility into the distribution, health, and performance of pNodes across the globe.

> **Community Project**: This platform is built by the community to support Xandeum operators and enthusiasts. It is not an official Xandeum product.

## What You Can Do

- **Monitor the Network** — View live statistics for 200+ pNodes worldwide
- **Track Node Performance** — CPU, RAM, storage, and uptime metrics
- **See Global Distribution** — Interactive map showing node locations
- **Analyze Token Data** — XAND price, liquidity, and market trends
- **Ask Xandbot** — AI assistant trained on Xandeum documentation
- **View Pod Credits** — Node credit scores and network rankings
- **Swap Tokens** — Trade XAND directly through Jupiter integration
- **Stake SOL** — Liquid staking for XANDsol with rewards calculator

## Network Concepts

### pNode (Physical Node)
A **pNode** is the physical hardware infrastructure — the server itself. It includes the machine, CPU, memory, storage, and network interface that provides resources to the Xandeum network.

### pod (Software Unit)
A **pod** is the software that runs on a pNode. It handles:
- Data replication and sharding
- Proof-of-Physical-Address (PoPA) verification
- Inter-node communication via pRPC

### Identity Model
Nodes are identified by their **Public Key (pubkey)**, not IP address:
- **Pubkey** — Permanent cryptographic identifier tied to the operator's Solana wallet
- **IP Address** — Ephemeral metadata used for geolocation, not identity

This ensures reputation and history persist even when a node changes networks.
