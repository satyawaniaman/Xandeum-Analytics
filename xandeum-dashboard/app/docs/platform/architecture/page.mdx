The Xandeum Analytics platform consists of two main components: a **Backend API** that syncs and serves data, and a **Frontend Dashboard** that visualizes it.

### Data Collection

The backend syncs pNode data every **30 seconds**:

1. **Fetch from pRPC** — Get latest pod list from gossip network
2. **Deduplicate** — Keep one record per IP (most recent)
3. **Geo-locate** — Look up country/city from IP address
4. **Fetch Stats** — Query each node's RPC for CPU/RAM/storage
5. **Persist** — Upsert to PostgreSQL by IP
6. **Cache** — Invalidate Redis cache

### Data Flow

1. **React Query** fetches data from backend API
2. **Caching** prevents unnecessary refetches (stale time: 30s)
3. **Optimistic updates** for responsive UI
4. **Real-time polling** keeps data fresh

## Deployment

- **Backend**: DigitalOcean VM with PM2 process manager
- **Database**: DigitalOcean Managed PostgreSQL
- **Cache**: Upstash Redis (serverless)
- **Frontend**: Vercel or any Node.js host
