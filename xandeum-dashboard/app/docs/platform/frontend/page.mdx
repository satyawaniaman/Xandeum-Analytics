# Dashboard Features

The dashboard provides a comprehensive view of the Xandeum network through several key features.

## Main Overview

The landing page at `/dashboard` provides a high-level snapshot:

### Network Stats
Four animated stat cards showing:
- **Total Nodes** — All registered pNodes
- **Online Nodes** — Currently active nodes
- **Public RPC** — Nodes with accessible RPC endpoints
- **Network Health** — Calculated from multiple factors

### Interactive Map
A vector-based world map showing:
- **Node Locations** — Dots for each node
- **Clustering** — Groups nearby nodes to prevent clutter
- **Tooltips** — Hover to see node count per region
- **Click to Explore** — View nodes in each area

### Status Distribution
A donut chart breaking down nodes by status:
- **Public RPC** — Accessible RPC, fully monitored
- **Private** — Online but RPC not accessible
- **Not Recently Seen** — No heartbeat in 5+ minutes
- **Unknown** — Status couldn't be determined

### Features
- **Search** — Find nodes by IP, pubkey, or country
- **Sort** — Click column headers to sort

## Node Details

Click any node to view its dedicated page at `/dashboard/nodes/:ip`:

### Information Displayed
- **Credit Score** — Lifetime pod credits
- **Network Rank** — Position among all nodes
- **Performance Tier** — Elite, High, Good, Average
- **Hardware Specs** — CPU, RAM, storage capacity
- **Network Traffic** — Packets sent/received, streams
- **Uptime** — How long the node has been running
- **Location** — Country and city with map

### Charts
- **CPU Usage** — Historical CPU utilization
- **Memory Usage** — RAM consumption over time
- **Storage** — Disk usage trends

## Network Analytics

The `/dashboard/network` page provides deeper analytics:

### Overview Tab
- **XAND Price Chart** — 24-hour price history
- **Liquidity Chart** — Total liquidity over time
- **Version Distribution** — Pie chart of software versions
- **Country Distribution** — Bar chart of nodes by country

### Performance Tab
- **Network Performance** — Aggregate throughput metrics
- **Coming Soon** — Historical trends, comparisons

## Trading & Staking

### Trade XAND

The `/dashboard/trade` page provides token swapping:
- **Price Chart** — Live XAND price with Moralis data
- **Swap Interface** — Trade any SPL token via Jupiter
- **Market Stats** — 24h volume, price change, liquidity
- **Token Info** — XAND description and links

### Stake SOL

The `/dashboard/stake` page offers liquid staking:
- **Staking Calculator** — Estimate rewards for different timeframes
- **SOL Price** — Live price from CoinGecko
- **XANDsol Info** — Benefits of liquid staking
- **External Link** — Redirects to XANDsol official staking portal
- **XAND Staking** — 16% APY staking via Realms DAO
