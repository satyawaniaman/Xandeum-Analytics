# Backend API

The backend API provides RESTful endpoints for accessing pNode data. All responses are JSON-formatted.

## Base URL

```
https://your-api-domain.com
```

## Endpoints

### GET /pnodes

Returns all pNodes with full details.

**Response:**

```json
      "id": "uuid",
      "ip": "123.45.67.89",
```

### GET /pnodes/stats

Returns network summary only (smaller payload).

**Response:**
```json
{
  "total": 232,
  "online": 188,
  "with_public_rpc": 37,
  "timestamp": "2025-12-20T10:00:00.000Z"
}
```

---

Returns details for a single node by IP address.

**URL Parameters:**

**Response:**

**Response:**

```json
  "timestamp": "2025-12-20T10:00:00.000Z",

```

## Caching

All endpoints are cached in Redis with a **30-second TTL**. This means:

- Data is at most 30 seconds old
- Repeated requests are fast (< 10ms)
- Sync service refreshes the source data every 30 seconds

## Rate Limiting

Currently, no rate limiting is applied to read endpoints. For production deployments, consider:

- Cloudflare rate limiting
- API key authentication
- Request throttling
