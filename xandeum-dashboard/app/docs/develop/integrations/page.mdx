# Integrations

The Xandeum platform does not operate in isolation. We leverage best-in-class tools from the ecosystem to provide a robust experience.

## Solana Ecosystem

### Wallets
We utilize **@solana/wallet-adapter** to support a wide range of wallets. This ensures users can connect securely without exposing their private keys.
- **Standard**: Fully supports the Solana Wallet Standard.
- **Mobile**: Supports Solana Mobile Stack (SMS) for native Android experiences.

### Jupiter Aggregator
We integrate directly with **Jupiter** for all asset exchange functionality. This provides deep liquidity and best execution for XAND tokens without requiring users to leave the dashboard.

## Infrastructure

### Redis
Used for high-speed caching of node status. The ephemeral nature of "live" status (online vs offline) makes Redis an ideal storage engine for the active node table.

### TimescaleDB
PostgreSQL with TimescaleDB extension is used for storing long-term metric history. This allows us to efficiently query "Average CPU usage over the last 30 days" for thousands of nodes.
