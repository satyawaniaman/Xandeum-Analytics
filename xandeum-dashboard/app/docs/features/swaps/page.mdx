# Token Swaps

The dashboard includes a fully integrated Decentralized Exchange (DEX) interface, allowing users to acquire XAND tokens directly within the platform. This feature is powered by **Jupiter**, the leading liquidity aggregator on Solana.

## Integration Architecture

### Jupiter Ultra API
We utilize the **Jupiter V6/Ultra API** to fetch the most efficient swap routes.
- **Liquidity Aggregation**: Jupiter scans multiple DEXs (Orca, Raydium, Meteora, etc.) to find the best price for XAND.
- **Smart Routing**: Trades may be split across multiple pools to minimize price impact and slippage.

### Fee Structure
<Callout title="Platform Fee" type="info">
  The dashboard charges a **0.20% platform fee** on all swaps, which helps support the development of the analytics infrastructure. This is independent of Solana network fees.
</Callout>

A standard **0.20% platform fee** is applied to every transaction executed through the dashboard.

### Failed Transactions
<Callout title="Slippage Warning" type="warn">
  Transactions may fail during high volatility if the slippage tolerance is too low. Ensure you have sufficient SOL for gas fees.
</Callout>
- **Fee Collector**: These fees are routed to the project's treasury wallet (`2gAwq...`) to support ongoing development.
- **Transparency**: The exact fee amount and the estimated output are displayed clearly before signing any transaction.

### Pricing Data
Real-time price feeds for XAND and other assets are sourced directly from the Jupiter Price API. We calculate:
- **USD Price**: derived from USDC pair liquidity.
- **Market Cap**: derived from circulating supply estimates.
- **24h Volume**: aggregated volume across all major pools.

## Supported Wallets
The swap interface supports all major Solana wallets via the Unified Wallet Adapter:
- Phantom
- Solflare
- Backpack
- Ledger (via hardware connection)
